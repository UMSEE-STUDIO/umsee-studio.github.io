# 수정 방법
#  1. "#" 로 시작하는 줄은 주석이다. 게임에 나오지 않는다.
#  2. "@" 로 시작하는 줄이 상황 ID다. ID는 코드가 참조하므로 바꾸지 말 것.
#  3. "[상황]" 줄은 이 대사가 언제 나오는지 설명한다(수정용 메모, 게임에 안 나옴).
#  4. "ko:" 줄이 한국어 대사다. 한 상황에 여러 줄이 있으면 순서대로 한 말풍선씩 나온다.
#  5. 같은 상황에 "ko:" 줄을 여러 묶음으로 쓰고 싶으면 "---" 로 묶음을 나눈다. 묶음 중 하나가 무작위로 나온다.
#  6. 다른 언어(en, ja, zh, fr, es)는 S7 번역 단계에서 같은 구조로 추가한다.
#  7. 줄 끝 "|" 는 말풍선 사이에 잠깐 멈춘다는 뜻이다(선택).
#  8. 말투 원칙: 설명하지 않는다. 안내문처럼 쓰지 않는다. 비둘기가 혼잣말하듯 은은하게.
# =====================================================================
